# AcrossTool Journal — Product Requirements Document (PRD)

## 1. 개요

### 1.1 제품명
**AcrossTool Journal**

### 1.2 제품 목적
사용자가 날짜 단위로 일과(루틴·할 일)를 기록하고 확인할 수 있는 저널 앱이다. PC·태블릿에서는 달력과 타임라인을 한 화면에서 동시에 보며 작업하고, 스마트폰에서는 달력 중심의 단순한 화면과 날짜 선택 시 팝업으로 일과를 관리한다.

### 1.3 핵심 가치
- **날짜 중심 일과 관리**: 달력에서 날짜를 선택하면 해당 날의 일과를 바로 확인·편집
- **반응형 UX**: 화면 너비에 따라 PC/태블릿과 모바일에 최적화된 레이아웃 제공
- **카테고리 필터**: 여러 종류의 일과를 카테고리별로 필터링해 집중적으로 조회

---

## 2. 사용자 및 사용 시나리오

### 2.1 대상 사용자
- 매일 반복되는 루틴(운동, 학습, 업무 등)을 기록하고 싶은 개인 사용자
- PC와 모바일을 오가며 동일한 저널 데이터를 확인하려는 사용자

### 2.2 주요 사용 시나리오

| 시나리오 | 플랫폼 | 사용자 행동 | 기대 결과 |
|----------|--------|-------------|-----------|
| 오늘 일과 확인 | PC/태블릿 | 앱 실행 후 달력에서 오늘 날짜 확인 | 우측 타임라인 패널에 오늘 일과 5줄이 상시 표시 |
| 과거/미래 날짜 일과 확인 | PC/태블릿 | 달력에서 다른 날짜 클릭 | 좌측 달력 선택 상태 변경, 우측 패널이 해당 날짜 일과로 갱신 |
| 모바일에서 일과 확인 | 스마트폰 | 달력에서 날짜 터치 | 하단 모달 팝업 카드에 해당 날짜 일과 5줄(체크박스) 표시 |
| 카테고리별 조회 | 전체 | AppBar 우측 필터 버튼 탭 | 선택한 카테고리에 해당하는 일과만 달력·타임라인에 반영 |

## 3. 기능 요구사항

### 3.1 메인 화면 (`AcrossToolMainScreen`)

#### 3.1.1 AppBar
| 항목 | 요구사항 |
|------|----------|
| 타이틀 | `AcrossTool Journal` 고정 표시 |
| 카테고리 필터 | 우측 상단 `filter_list_alt` 아이콘 버튼 |
| 필터 동작 | 탭 시 카테고리 선택 UI 표시, 선택된 카테고리 기준으로 달력·일과 목록 필터링 |

#### 3.1.2 날짜 선택 상태
- 앱 진입 시 `_selectedDay`는 **오늘 날짜**(`DateTime.now()`)로 초기화
- 사용자가 달력에서 날짜를 선택하면 `_selectedDay` 갱신
- 선택된 날짜는 달력 UI와 타임라인/팝업 콘텐츠의 기준일로 사용

---

### 3.2 반응형 레이아웃

`LayoutBuilder`로 실시간 화면 가로폭(`constraints.maxWidth`)을 감지하며, **600px**을 브레이크포인트로 사용한다.

#### 3.2.1 PC / 태블릿 (가로폭 ≥ 600px) — 2분할 레이아웃

```
┌─────────────────────────────────────────────────────────┐
│  AppBar: AcrossTool Journal              [필터]         │
├──────────────────────────┬──────────────────────────────┤
│                          │                              │
│   달력 영역 (60%)         │   타임라인 패널 (40%)         │
│   - 정갈한 달력 위젯      │   - 선택된 날짜의 일과        │
│   - 선택된 날짜 하이라이트 │   - 5줄 타임라인 상시 노출    │
│                          │   - 스크롤 없이 한눈에 확인   │
│                          │                              │
└──────────────────────────┴──────────────────────────────┘
```

| 영역 | 비율 | 배경 | 설명 |
|------|------|------|------|
| 좌측 달력 | `flex: 6` (60%) | 흰색 (`Colors.white`) | 월별 달력, 날짜 선택, 선택일 표시 |
| 구분선 | 1px | `VerticalDivider` | 좌우 패널 시각적 분리 |
| 우측 타임라인 | `flex: 4` (40%) | 연한 회색 (`Colors.grey[50]`) | 선택된 날짜의 **오늘 일과 5줄** 타임라인, 항상 화면에 노출 |

**PC 전용 UX 원칙**
- 하단 타임라인 없음 — 우측 패널이 그 역할을 대체
- 날짜 변경 시 우측 패널만 갱신, 전체 화면 전환 없음

#### 3.2.2 스마트폰 (가로폭 < 600px) — 원스크린 달력

```
┌─────────────────────────┐
│  AppBar: ...    [필터]  │
├─────────────────────────┤
│                         │
│      달력 (전체 화면)     │
│                         │
│   날짜 터치 → 팝업 호출   │
│                         │
└─────────────────────────┘
         ↓ 날짜 터치
┌─────────────────────────┐
│  모달 Bottom Sheet      │
│  (높이 300, radius 20)  │
│  오늘 일과 5줄 체크박스   │
└─────────────────────────┘
```

| 항목 | 요구사항 |
|------|----------|
| 레이아웃 | 달력만 전체 화면 사용, **하단 고정 타임라인 없음** |
| 날짜 터치 | `showModalBottomSheet`로 팝업 카드 표시 |
| 팝업 스타일 | 상단 모서리 `borderRadius: 20`, 패딩 20, 높이 300 |
| 팝업 콘텐츠 | 선택된 날짜의 **일과 5줄**, 각 줄은 **체크박스** 형태 |
| 팝업 닫기 | 바깥 영역 탭 또는 스와이프 다운으로 닫기 (Flutter 기본 동작) |

**모바일 UX 원칙**
- 달력 가독성 최우선 — 보조 UI는 팝업으로만 노출
- PC와 동일한 5줄 일과 데이터 구조 유지, 표현 방식만 체크박스 팝업으로 변경

---

### 3.3 일과 타임라인 (5줄)

#### 3.3.1 데이터 구조 (개념)
- 하루당 최대 **5개** 일과 슬롯
- 각 슬롯: 텍스트 라벨 + 완료 여부(체크박스)
- 날짜(`_selectedDay`) + 카테고리 필터 조건에 따라 표시 항목 결정

#### 3.3.2 표시 규칙
| 플랫폼 | 표시 위치 | 인터랙션 |
|--------|-----------|----------|
| PC/태블릿 | 우측 타임라인 패널 | 인라인 체크박스·텍스트 편집 |
| 모바일 | Bottom Sheet 팝업 | 체크박스 토글, 팝업 내 5줄 고정 |

#### 3.3.3 동작
- 날짜 변경 시 해당 날짜의 5줄 데이터 로드
- 카테고리 필터 적용 시 필터에 맞는 줄만 표시하거나, 빈 슬롯 처리 정책 정의 필요 *(구현 단계에서 확정)*

---

### 3.4 카테고리 필터

| 항목 | 요구사항 |
|------|----------|
| 진입점 | AppBar 우측 `IconButton` (`Icons.filter_list_alt`) |
| UI | 카테고리 목록 선택 (드롭다운, 칩, 또는 바텀시트 — 구현 시 결정) |
| 적용 범위 | 달력 마커/표시 및 타임라인·팝업의 일과 목록 |
| 기본값 | 전체 카테고리 (필터 없음) |
| 상태 유지 | 세션 내 선택 카테고리 유지; 앱 재시작 시 정책 *(구현 시 결정)* |

## 4. 비기능 요구사항

### 4.1 반응형
- 브레이크포인트: **600px** (`constraints.maxWidth >= 600`)
- 창 크기 변경 시 `LayoutBuilder`가 즉시 레이아웃 전환 (PC ↔ 모바일 모드)

### 4.2 플랫폼
- Flutter 기반 — Windows PC, 태블릿, iOS/Android 스마트폰 대응
- 동일 코드베이스에서 반응형 분기

### 4.3 UI/UX
- 달력: 정갈하고 읽기 쉬운 디자인
- PC: 정보 밀도 높은 2분할, 모바일: 단순·터치 친화적
- 모달 팝업: 둥근 상단 모서리, 충분한 터치 영역

### 4.4 접근성 *(권장)*
- 체크박스·날짜 셀에 시맨틱 라벨
- 필터 버튼에 `tooltip` 또는 스크린 리더용 라벨

## 9. 참고 구현

### 9.1 웹 MVP (현재 `main`)

### 9.2 Flutter 목표 (PRD 원본)

- 상태: `_selectedDay: DateTime`
- 반응형: `LayoutBuilder` + `constraints.maxWidth >= 600`
- PC: `Row` → `Expanded(flex: 6)` + `VerticalDivider` + `Expanded(flex: 4)`
- 모바일: `showModalBottomSheet` — `height: 300`, `borderRadius.vertical(top: 20)`
